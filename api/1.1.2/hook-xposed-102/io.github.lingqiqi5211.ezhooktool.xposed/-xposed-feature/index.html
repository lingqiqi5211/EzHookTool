XposedFeature

enum XposedFeature : Enum<XposedFeature>

libxposed 的可选特性。

每个特性对应一组高版本 API 才提供的能力。isSupported 按当前 framework 实际提供的类型和方法判定， 而不是只看版本号，因此可以直接用来决定要不要走某条代码路径：

if (XposedFeature.HOT_RELOAD.isSupported) {
    // 走热重载流程
}
