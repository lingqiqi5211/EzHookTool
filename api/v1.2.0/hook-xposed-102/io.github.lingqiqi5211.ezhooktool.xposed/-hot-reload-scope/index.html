HotReloadScope

class HotReloadScope

HotReloadSession 的跨代状态与外部资源清理容器。

只存放 system / system_server / target app classloader 的对象。模块自己的对象、lambda 或包含它们的 容器不能跨代保存；本类会尽早拒绝常见错误，framework 仍会执行最终校验。
