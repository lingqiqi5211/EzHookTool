ReflectCacheStats

data class ReflectCacheStats(val generation: Long, val entries: Int, val capacity: Int, val hits: Long, val misses: Long, val evictions: Long, val skippedOversizeResults: Long)

反射缓存的只读计数快照，由 EzReflect.cacheStats 读取。

只含数字，不引用 Class、ClassLoader、成员对象、配置或异常，因此读一次不会延长任何加载器的存活。 计数属于一代缓存状态：init、reset、clearCache 和配置切换会发布新状态，计数从零开始， 可用 generation 判断快照是否来自同一次状态发布。
